Randomized hyperparameter search for XGBoost, Random Forest, and Gradient Boosting residual correctors

Tunes all three tree-based models via RandomizedSearchCV (10 sampled configurations each) to correct the LSTM's residual error, using an identical 186-dimensional feature set across all three (flattened 8-week predictor window, week number, LSTM prediction), so results are directly comparable. Selects the best-performing configuration per model based on R² against the held-out set.
