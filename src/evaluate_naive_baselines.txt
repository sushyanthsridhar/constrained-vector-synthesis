Persistence and climatology naive baselines

Computes the two naive forecasting baselines reported alongside the hybrid model: persistence, which forecasts each trap-week from that same trap's own previous observed week (lag reset independently per trap; the week-1 forecast uses the trap's last real observation before the evaluation window, which the input file must supply with Week <= 0), and climatology, which forecasts each trap-week from the historical mean for that week number, pooled across the 127 training traps and the 2009-2013 seasons. Both are evaluated against the same held-out 2023-2024 test season (31 traps, 28 weeks, 868 trap-weeks total), using the pooled-MSE convention described in the paper, errors pooled across all test trap-weeks rather than averaged per trap first. Both baselines are scored over the same 868 trap-weeks (evaluation weeks 1 to 28 only). Outputs both baselines' MSE and trap-week counts to a single CSV. A skill-score helper (compute_skill_score) is provided for comparing a model's MSE against either baseline, matching the skill-score definition in Appendix B, but is not invoked here since it requires the model's own MSE as an external input.
