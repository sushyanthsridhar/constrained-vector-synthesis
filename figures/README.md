**Note on provenance:** these are static reference copies of the manuscript's published figures, not files regenerated by the scripts in `src/`. Reproducing Figures 5-9 computationally requires the raw surveillance data and the upstream artifacts documented in the main `README.md`'s "Upstream artifact contracts" section; once those are available, `src/synthesize_egg_count_series.py`, `src/validate_spectral_fidelity.py`, `src/classify_breeding_intensity.py`, and `src/forecast_hybrid_model.py` produce the underlying plots, but currently these scripts only display them rather than saving them out in this format.
