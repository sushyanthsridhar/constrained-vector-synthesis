# figures/

Plots produced by the pipeline, corresponding to the paper's figures, for example:

- `synthetic_vs_empirical.png` (Figure 5) — from `src/synthesize_egg_count_series.py`
- the DFT amplitude-spectrum comparison (Figure 6) — from `src/validate_spectral_fidelity.py`
- the breeding-intensity classification and forecasting-performance plots (Figures 4, 7, and the appendix correlation figures)

Nothing is checked into this folder — these are regenerated locally when the pipeline is run against the raw surveillance data (see the top-level `DATA_README`).
