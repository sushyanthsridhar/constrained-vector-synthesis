# tables/

All 13 tables from the manuscript (main text and appendices), as static reference CSVs transcribed directly from the accepted/submitted paper:

| File | Paper table | Contents |
|---|---|---|
| `table1_literature_comparison.csv` | Table 1 | Literature comparison across six methodological characteristics |
| `table2_feature_set.csv` | Table 2 | Feature set for the hybrid forecasting model |
| `table3_lstm_config.csv` | Table 3 | LSTM architecture and training configuration |
| `table4_xgb_input_features.csv` | Table 4 | Input features for the XGBoost residual model |
| `table5_performance_comparison.csv` | Table 5 | Final-test performance comparison (with/without synthetic augmentation, all models) |
| `table6_fold_level_results.csv` | Table 6 | Per-trial results for the standalone LSTM and hybrid model |
| `table7_hybrid_comparison_optimized.csv` | Table 7 | Hybrid model vs. baseline comparison (Mean Predictor, GB, RF, LSTM) |
| `table8_sensitivity_analysis.csv` | Table 8 | Augmentation design parameter sensitivity analysis |
| `table9_notation.csv` | Table 9 (Appendix A) | Notation used throughout the manuscript |
| `table10_performance_metrics.csv` | Table 10 (Appendix B) | Forecast performance metrics and skill scores |
| `table11_lstm_features.csv` | Table 11 (Appendix C) | Full 23-feature definitions for the LSTM model |
| `table12_rf_gb_config.csv` | Table 12 (Appendix E) | Default scikit-learn hyperparameters for the untuned RF/GB baselines |
| `table13_avg_correlation.csv` | Table 13 (Appendix F) | Average seasonal correlation between environmental indices and egg counts |

**Note on provenance:** these are static reference copies of the manuscript's published tables, not files regenerated by the scripts in `src/`. Reproducing Tables 5–8 computationally requires the raw surveillance data and the upstream artifacts documented in the main `README.md`'s "Upstream artifact contracts" section; once those are available, `src/forecast_hybrid_model.py`, `src/tune_residual_models.py`, and `src/validate_spectral_fidelity.py` compute the underlying numbers, but currently print/hold them in memory rather than writing them out in this format.
